# RetailOps

A personal full-stack retail management application inspired by everyday checkout and inventory workflows.

## Project Goal

Build a web application for managing fictional store products, inventory, simulated checkout transactions, and sales reports.

## Technology Stack

- Java
- Spring Boot
- React
- JavaScript
- PostgreSQL
- Git and GitHub
